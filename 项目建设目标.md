# 5. 最关键的设计：模型和 Runtime 分离

现在你的包里：

```text
yolov9t/
├── yolov9t_detector.py
├── yolov9t_webserver.py
└── model/
```

实际上把：

```text
模型
算法
Web服务
部署
```

全耦合了。

新系统建议变成：

```text
runtime/
    detection/
        detector.py
        postprocess.py

model/
    model.xpu

config/
    model.yaml
```

也就是说：

```text
                    Runtime
                       │
           ┌───────────┼───────────┐
           │           │           │
         YOLOv8      YOLOv10     YOLOv11
           │           │           │
           └───────────┼───────────┘
                       │
                  Model Adapter
```

这样 YOLOv10 和 YOLOv9t 的 HTTP 服务代码不需要重复。
